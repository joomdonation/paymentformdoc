### Chapter 3

# Frontend Display

Choose a display option based on what visitors need to do and where they should do it.

| What visitors need to do | Joomla option |
| --- | --- |
| Choose from several forms on a dedicated page, such as a page for fees and donations | [Forms List menu item](/frontend-items/display-forms#create-a-forms-list-page) |
| Find links to several forms on an existing page, such as in a sidebar | [Payment Form - Forms List module](/frontend-items/display-forms#show-form-links-in-a-module-position) |
| Open one specific form from the site navigation | [Form Modern Layout menu item](/frontend-items/display-a-single-form#give-a-form-its-own-page) |
| Fill in one form directly on an existing page, in a position provided by the site template | [Payment Form - Form module](/frontend-items/display-a-single-form#show-a-form-in-a-module-position) |
| Fill in a form within an article, such as below an explanation of a fee | [Content - Payment Form plugin](/frontend-items/display-a-single-form#embed-a-form-in-a-joomla-article) |
| Review past payments and download available PDF invoices | [Payment History menu item](/frontend-items/payment-history) |

Before adding forms to the site, [create and publish them](/basic-setup/forms/add-new-form). Use each form's **Access**, **Publish Up**, and **Publish Down** settings to control who can open it and when it is available.
