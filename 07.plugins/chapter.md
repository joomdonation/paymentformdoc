### Chapter 3

**Payment Form** provides several additional plugins that extend its functionality and help you customize how payment forms work.

These plugins offer useful features such as managing Joomla user group assignments, limiting the number of payments accepted by a form, integrating with external services through webhooks, executing custom PHP scripts, and synchronizing payment records with Google Sheets.

Select a plugin below to learn more about its features and configuration.
