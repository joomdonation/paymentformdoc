The current Payment Form package requires Joomla 4.4.0 or later and PHP 7.4.0 or later. Joomla 5 and 6 require newer versions of PHP.

| Joomla version | Minimum PHP version for Joomla with Payment Form |
| --- | --- |
| [Joomla 4.4](https://manual.joomla.org/docs/4.4/get-started/technical-requirements/) | 7.4.0 |
| [Joomla 5](https://manual.joomla.org/docs/5.4/get-started/technical-requirements/) | 8.1.0 |
| [Joomla 6](https://manual.joomla.org/docs/get-started/technical-requirements/) | 8.3.0 |

Use a MySQL or MariaDB database and check the linked Joomla requirements for the database and web server versions your site needs.

For Joomla 3, use the legacy Payment Form release, which receives maintenance fixes only.
