Use **Payment Form - Forms List** to show links to forms in a template position. Choose the forms to include under **Forms** and set the maximum number of links in **Number Forms**. Leave **Forms** empty to include any form the visitor can open, up to that limit.

For the setup steps, default limit, and what to check when a link is missing, see [Show form links in a module position](/frontend-items/display-forms#show-form-links-in-a-module-position).
