# Plugins and Integrations

Enable these Joomla plugins under **System → Plugins**, then follow the guide for the feature you want to use. If a plugin adds settings for individual forms, reopen the form editor after enabling it. The Payment Form package includes the plugins listed here, with Google Sheets available as a separate paid add-on.

| What you want to do | Setup guide |
| --- | --- |
| Prefill fields from a Joomla, Membership Pro, Community Builder, or JomSocial profile | [Automatic Form Field Population](/automatic-form-field-population) |
| Subscribe customers to a newsletter after payment | [AcyMailing or Mailchimp](/newsletter-integrations) |
| Sell a code that a customer can redeem in another Joomla extension | [Sell Vouchers & Coupons](/sell-vouchers-and-coupons) |
| Grant access to restricted Joomla content or update a user's group membership after payment | [Joomla User Groups](/plugins/payment-form-joomla-user-groups) |
| Close a form after it reaches a set number of payments | [Limit Payments](/plugins/payment-form-limit-payments) |
| Require the final amount on a form to fall within a set range | [Validate Payment Amount](/plugins/validate-payment-amount) |
| Send payment data to a CRM or another service over HTTP | [Webhook](/plugins/payment-form-webhook) |
| Run custom PHP code when a payment is saved or succeeds | [PHP Script](/plugins/payment-form-php-script) |
| Synchronize a form's payment records to a tab in Google Sheets | [Google Sheets](/plugins/payment-form-google-sheet) |
| Embed a payment form in a Joomla article | [Content - Payment Form](/frontend-items/display-a-single-form#embed-a-form-in-a-joomla-article) |
| Create a Joomla account only once payment succeeds | [Payment Form - Account Creation](/basic-setup/forms/customize-form#registration-and-login) |
| Assign invoice numbers and offer PDF invoices | [Payment Form - Invoice Generator](/getting-started/configuration/invoice-settings) |
| Run cleanup jobs through Joomla Scheduler | [Task - Payment Form](/scheduled-tasks) |
| Install Payment Form updates through Joomla | [Installer - Payment Form](/getting-started/installation#update) |

To configure a gateway or an offline method, open [Payment Plugins](/basic-setup/payment-plugins) in the Payment Form component.
